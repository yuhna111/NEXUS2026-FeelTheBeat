# Chạy lại C-0012 và F-0002 (việc của TV2)

TV1 sửa câu hỏi C-0012 và F-0002 ngày 28/11/2026 (`docs/tv1_review_tv3_v03.md`, mục 6). Đầu ra và ngữ cảnh cũ của hai câu này đã được xoá khỏi `outputs/tv3_v0.3/` và `outputs/contexts/tv3_v0.3/`, nên `rag.run_inference` sẽ chỉ chạy đúng 2 câu (các câu khác đã có, được bỏ qua).

1. **Truy xuất lại** (máy có Qdrant + BGE-M3; ghi đè cả file ngữ cảnh, 58 câu còn lại cho kết quả như cũ):
   ```
   python -m rag.retrieve_contexts --config C2 --bench data/benchmark/tv3_v0.3.jsonl
   python -m rag.retrieve_contexts --config C3 --bench data/benchmark/tv3_v0.3.jsonl
   ```
2. **Gemini** (cần key, khoảng 8 lượt gọi):
   ```
   for c in C0 C2 C3 C4; do python -m rag.run_inference --config $c --bench data/benchmark/tv3_v0.3.jsonl --models gemini-flash; done
   ```
3. **Qwen 7B** (Colab vLLM như tuần 3):
   ```
   for c in C0 C2 C3 C4; do python -m rag.run_inference --config $c --bench data/benchmark/tv3_v0.3.jsonl --models qwen-7b; done
   ```
   Mỗi lệnh phải in `+1 mới` hoặc `+2 mới`; nếu in `+0 mới` là chưa kéo bản đã xoá đầu ra cũ.
4. **Chấm lại:** xoá `"C-0012", "F-0002"` khỏi `OUTDATED_QIDS` trong `eval/run_w3_eval.py`, rồi `python eval/run_w3_eval.py`; dòng "Bỏ ... đầu ra" không còn xuất hiện.
